# 任务卡特殊效果修订记录

## 结论

这次问题不是卡牌数据缺失，而是 gallery 之前只展示了 `quest_requirement` 与 `quest_reward`，没有完整消费 Lua 里的特殊字段：

- 万能冒险者需求存放在 `quest_any_kind_requirement`，不是 `quest_requirement`。
- 完成时的额外支付、按支付职业结算、剧情任务持续效果分别存放在 `played_effects`、`triggered_effects`、`continuous_effects`。
- 现在 gallery 已新增独立的“效果”行，并把这些字段转成中英可读文本；英文原文仍保留，中文显示优先。

## 本次修正

| 类型 | 旧问题 | 现在处理 |
| --- | --- | --- |
| 单值奖励字段 | 少数基础任务使用 `quest_reward = "25v";`，旧导出器只识别 `{ "25v" }` 数组，导致奖励空白 | `quest_requirement`、`quest_reward`、`static_resources`、`owner_resources` 都改为同时支持数组与单字符串 |
| 万能冒险者需求 | `quest_any_kind_requirement` 没有并入需求，导致部分任务需求少人 | 导出时转为 `u` 资源，例如 `4 wild`、`7 wild` |
| 完成时按支付职业奖励 | 只保留 raw effect，不显示 | 生成“每使用 1 个法师抽 1 张阴谋卡”等效果文本 |
| 完成后立即额外支付 | 只保留 raw effect，不显示 | 生成“立即返还 4 个盗贼/战士得 10 VP”等效果文本 |
| 剧情任务持续效果 | `triggered_effects` / `continuous_effects` 不显示 | 生成“每当你拿取某类任务/完成某类任务/获得某类资源时……”等效果文本 |

## 注意项

- Excel 中 `Root Out Loviatar's Faithful` 与 Lua `card_name` 中的 `Root Out Loviator's Faithful` 拼写不完全一致；按 D&D 神祇名应为 `Loviatar`，但 gallery 的英文留档仍保留解包原字段。
- Excel 颜色缩写沿用原表：`wh / oj / bl / pu` 分别对应牧师、战士、盗贼、法师。
- 这些效果现在作为 `quest_effects_text` 与 `quest_effects_text_zh` 独立输出，便于后续翻译校对，也避免误混进奖励字段。
